WANDER is a human-trajectory retrieval-augmented framework for computer-use agents. It converts historical desktop operation trajectories into reusable canonical units and uses them to reduce planning drift during long-horizon GUI tasks.

**Status:** AAAI 2027 conference submission. [View submission](https://openreview.net/forum?id=NKKGCmqWej).

## Contributions

- Built a Reflection-Planner-Grounding-Code Agent execution loop from screenshot perception to PyAutoGUI execution.
- Constructed a canonical unit knowledge base with multi-path statistics and historical transition relationships.
- Designed dual-channel retrieval that combines FAISS interface-state search with successor-operation recall.
