SE-Explorer Agent reconstructs a fixed RAG workflow into a lightweight ReAct loop that can retrieve documents, localize code, collect evidence, propose solutions, and verify results based on task state.

## Contributions

- Integrated multimodal document retrieval for body text, tables, formulas, and figures.
- Composed code search, file reading, shell operations, patch generation, and test suggestion tools.
- Added trajectory logging, evidence memory, and verifier mechanisms for traceable tool use.
